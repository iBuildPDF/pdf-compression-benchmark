# Benchmark Test Files

This directory documents the source files used in the iBuildPDF PDF Compression Benchmark.

## File categories

- Text-heavy
- Scanned
- Photo-heavy
- Presentation
- Mixed-content
- Already optimized

## File policy

Only use:

- self-created documents
- synthetic test documents
- public-domain documents
- files licensed for redistribution

Do not upload confidential, customer, copyrighted, or private documents.

Each benchmark result should clearly identify which source-file category was tested.
