# PDF Compression Benchmark Methodology

This benchmark measures how different kinds of PDF documents respond to compression.

## Document categories

- Text-heavy PDF
- Scanned PDF
- Photo-heavy PDF
- Presentation export
- Mixed-content PDF
- Already optimized PDF

## Measurements

Each test records:

- Original file size
- Compressed file size
- Percentage reduction
- Processing time
- Page count
- Compression mode
- Whether text remains selectable
- Whether links remain functional
- Whether PDF forms remain functional
- Visible quality impact
- Test date

## Testing rules

The same source file must be used when comparing compression modes.

Tests should be performed under comparable conditions.

Only actual measured results are published.

Estimated or fabricated benchmark results must never be included.
