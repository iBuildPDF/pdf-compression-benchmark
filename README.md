# iBuildPDF PDF Compression Benchmark

An open benchmark for measuring PDF compression across different types of documents.

## Why this project exists

PDF compression results vary significantly depending on the document itself.

A text-heavy PDF behaves differently from:

- a scanned document
- a photo-heavy brochure
- a presentation export
- a mixed text and image file
- an already optimized PDF

This project documents a repeatable methodology for measuring those differences.

## Metrics

For each test file, we record:

- Original file size
- Compressed file size
- Percentage reduction
- Processing time
- Document type
- Compression mode
- Whether text remains selectable
- Whether links/forms remain functional
- Visible quality impact

## Test categories

- Text-heavy PDF
- Scanned PDF
- Photo-heavy PDF
- Presentation export
- Mixed-content PDF
- Already optimized PDF

## Benchmark principles

Results are published only after actual testing.

No estimated or fabricated benchmark values are included.

The same source files and clearly documented compression settings should be used whenever comparisons are repeated.
